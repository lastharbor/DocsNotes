# Резервное копирование

## Виды резервного копирования

| Вид | Что копируется |
|---|---|
| Полное | все данные |
| Дифференциальное | изменения с момента последнего полного копирования |
| Инкрементальное | изменения с момента последнего копирования любого вида |

## Бэкап базы данных MySQL

Дамп базы:

```bash
sudo mysqldump -u root mydb > /tmp/dump.sql
```

Дамп сразу в архив:

```bash
sudo mysqldump -u root mydb | gzip > /tmp/dump.sql.gz
```

Восстановление:

```bash
sudo mysql -u root mydb < /tmp/dump.sql
gunzip < /tmp/dump.sql.gz | sudo mysql -u root mydb
```

!!! warning "Пароль в командной строке"
    Если нужен пароль, указывайте `-p` без значения: `mysqldump` спросит его сам. Пароль в самой команде виден в `ps` и остаётся в истории шелла.
