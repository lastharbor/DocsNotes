# Нереляционные базы данных

## Теорема CAP

Для любой реализации распределённых вычислений можно обеспечить не более двух из трёх свойств:

- согласованность (Consistency)
- доступность (Availability)
- устойчивость к разделению (Partition tolerance)

## Основные модели организации данных

- иерархическая
- сетевая
- реляционная
- нереляционная
