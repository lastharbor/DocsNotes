# VIM

## Перемещение по словам

| Клавиша | Куда переместится курсор |
|---|---|
| ++w++ | в начало следующего слова |
| ++e++ | в конец слова |
| ++b++ | в начало слова (движение назад) |

Заглавные ++shift+w++, ++shift+e++, ++shift+b++ делают то же, но считают словом всё, что разделено пробелами.
