:::note[Коротко]
Интерактивный Bash-скрипт скачивает образ MikroTik CHR нужной версии и создаёт из него виртуальную машину в Proxmox.
:::

## Проблема

Нужно создавать несколько машин с CHR в виртуальном окружении, и делать это руками долго: скачать образ, распаковать, сконвертировать, создать ВМ, подключить диск.
Скрипт автоматизирует эти шаги и оставляет вам только выбор версии, номера ВМ и имени.

## Что делает скрипт

1. Проверяет наличие каталога `/root/temp` и создаёт его при необходимости.
2. Показывает уже скачанные образы `chr-*.img`.
3. Предлагает выбрать готовый образ по номеру или ввести версию RouterOS. Новую версию скачивает с `download.mikrotik.com` и распаковывает.
4. Показывает список ВМ (`qm list`) и спрашивает VMID и имя новой машины.
5. Конвертирует образ из raw в qcow2 и кладёт его в каталог хранилища ВМ.
6. Создаёт ВМ командой `qm create` и подключает диск.

## Запуск

<LinkButton href="../files/installchr.sh" download>Скачать installchr.sh</LinkButton>

Скрипт запускают на ноде Proxmox от `root`:

```bash
chmod +x installchr.sh
./installchr.sh
```

## Параметры под себя

Значения зашиты в скрипт, при другой конфигурации Proxmox их нужно поменять:

| Что | Значение в скрипте |
|---|---|
| Хранилище | `large-pool` (каталог `/mnt/pve/large-pool/images`) |
| Сетевой мост | `vmbr0` |
| Ресурсы ВМ | 1 сокет, 1 ядро, 256 МБ памяти |
| Тип диска | `virtio0`, формат qcow2 |
| Каталог образов | `/root/temp` |

:::danger[Перезапись каталога ВМ]
Если каталог `/mnt/pve/large-pool/images/<VMID>` уже существует, скрипт удаляет его вместе со всем содержимым. Скрипт проверяет, что VMID состоит только из цифр, но номер занятой ВМ он не отсеивает: сверяйтесь со списком `qm list`.
:::
